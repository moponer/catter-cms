# 菜单管理功能检查与修复报告

## 检查时间
2026-03-25

## 发现的问题及修复

### 1. 后台菜单项未过滤 enabled 字段 ✅ 已修复
**问题**：`GetMenuItemsWithChildren` 函数获取所有菜单项，没有过滤 `enabled=false` 的项。

**修复**：修改 `gin-app/internal/models/menu.go`，在查询时添加 `enabled = ?` 条件：
```go
// 修改前
DB.Where("menu_id = ?", menuID).Order("sort ASC").Find(&allItems)

// 修改后
DB.Where("menu_id = ? AND enabled = ?", menuID, true).Order("sort ASC").Find(&allItems)
```

### 2. 前台模板使用硬编码菜单 ✅ 已修复
**问题**：所有前台模板（home.html、article_show.html 等）都使用硬编码的 HTML 菜单，而不是从后端获取的动态菜单。

**影响**：用户在后台管理的菜单配置无法在网站上生效。

**修复**：修改了 dianyan-blog 主题的 10 个模板文件，全部使用动态菜单变量：
- `home.html`
- `article_list.html`
- `article_show.html`
- `category.html`
- `tag.html`
- `archives.html`
- `page.html`
- `search.html`
- `categories.html`
- `tags.html`

**修改内容**：
1. 导航菜单使用 `{{ range .headerMenu.Items }}` 遍历
2. Footer 链接使用 `{{ range .footerMenu.Items }}` 遍历
3. 支持子菜单 `{{ range .Children }}`
4. 支持 Target 属性（新窗口打开）

### 3. 前台模板下拉菜单样式缺失 ✅ 已修复
**问题**：虽然支持多级菜单，但 CSS 没有下拉菜单样式。

**修复**：在 `base.css` 中添加了下拉菜单样式：
```css
.nav-menu li { position: relative; }
.nav-menu .sub-menu {
    display: none;
    position: absolute;
    /* 下拉效果样式 */
}
.nav-menu li:hover > .sub-menu { display: block; }
```

### 4. 前端菜单项缺少启用/禁用开关 ✅ 已修复
**问题**：前端菜单编辑表单没有启用/禁用选项。

**修复**：在 `MenuList.vue` 中添加：
1. `MenuItem` 接口添加 `enabled?: boolean` 字段
2. `itemForm` 添加 `enabled: true` 属性
3. 编辑表单添加 `el-switch` 开关
4. `handleAddItem` 和 `handleEditItem` 添加 `enabled` 处理
