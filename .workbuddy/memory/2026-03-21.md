## 主题管理 + SSR 修复（晚间）

### 问题诊断
1. **SSR 问题（误报）**：日志显示 "Loaded theme: catter-blog/catter-cms-official/enterprise-website" 是因为 `LoadThemes()` 遍历所有主题目录加载元数据。所有主题都加载到内存是**正常设计**（管理后台需要管理所有主题），SSR 渲染只用 `GetActiveTheme()` 始终只有1个主题
2. **管理后台主题列表缺失（真实问题）**：`ThemeSettings.vue` 直接渲染配置，没有主题列表页，不符合 Halo 模式

### 修复内容
1. **新增 ThemeList.vue** - 主题列表页：展示所有主题卡片、激活状态徽章、激活/配置/预览按钮、上传主题
2. **改造 ThemeSettings.vue** - 改为纯配置页，从 URL 参数 `:slug` 获取主题，显示主题信息 + is_active 状态
3. **更新路由**：`/themes` → ThemeList，`/themes/:slug` → ThemeSettings
4. **API 补充**：`listThemes()` + `getThemeConfigFull()` 函数
5. **嵌套结构修复**：`ThemeSettings.vue` 中 `getNestedValue`/`flattenToNested` 处理后端嵌套存储与前端扁平表单的双向转换
6. **Gin 日志修复**：`log.SetOutput(os.Stderr)` + 强制 `gin.SetMode(gin.ReleaseMode)` 避免 debug 日志干扰 HTTP 响应
