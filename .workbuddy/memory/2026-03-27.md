## 主题配置默认值加载问题修复
- **问题**：shengyi-logistics 首页 Hero 按钮 `heroCta1Link`/`heroCta2Link` 点击无反应
- **根因**：主题数据库无配置记录时，`getConfig` 返回空字符串导致链接为 `#`
- **深层原因**：`LoadTheme` 只从 YAML 的 `config:` 节点加载配置，但 shengyi-logistics 只有 `configDefinition`（定义配置项），没有 `config`（实际配置值）
- **修复**：`theme.go` 的 `LoadTheme` 函数新增逻辑：从 `configDefinition[].fields[].default` 提取默认值初始化 `theme.Config`
- **影响**：所有未在数据库保存过配置的主题，现在都能正确使用 theme.yml 里的 default 值

## Hero 背景图透明度配置功能
- **需求**：管理后台上传 Hero 背景图后，需要能调整透明度
- **实现**：
  1. theme.yml 新增 `heroBgOpacity` 字段（slider 类型，0-100，默认 25）
  2. home.css 用 CSS 变量 `--hero-bg-opacity` 替换硬编码 `opacity: 0.25`
  3. home.html 模板用 `divide100` 函数将 0-100 转换为 0.00-1.00
- **新增模板函数**：`mul`（乘法）、`div`（除法，支持 float64）、`divide100`（百分比转小数）
- **冲突修复**：删除原有 `div` 函数（int 整数除法），用新的 `div`（支持 float64）替换
