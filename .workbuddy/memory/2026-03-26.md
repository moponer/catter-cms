## duocai-blog theme.yml 双BOM修复（13:17）

**现象**：后台看不到 duocai-blog，前台显示另一主题
**根本原因**：`theme.yml` 文件头有双 BOM（`EF BB BF EF BB BF`），Go yaml 库无法解析，报 `line 8: did not find expected key`，主题整个被跳过
**双BOM来源**：PowerShell `WriteAllText` 在已有 BOM 的文件上叠加了一个新 BOM
**修复**：Python `open(..., encoding='utf-8-sig')` 读取 + `open(..., encoding='utf-8', newline='\n')` 写回 → 单 BOM → yaml 正常解析
**教训**：以后修改 YAML/配置文件禁止用 PowerShell 的 `[IO.File]::WriteAllText`，用 Python 或直接编辑工具处理
**前台主题**：数据库 `settings.active_theme = "catter-cms-official"`，主人需在后台手动激活 duocai-blog
