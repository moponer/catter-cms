## 标签功能增强

**问题**：标签选择器不支持创建新标签

**解决方案**：
- 后端 PostRequest 添加 `tag_names []string` 字段
- 后端自动创建不存在的标签（按名称）
- 前端标签选择器使用 `allow-create` 模式，输入新标签名按回车创建

**字段变化**：
```javascript
// 旧：使用 ID
{ tag_ids: [1, 2, 3] }

// 新：使用名称
{ tag_names: ['Vue', 'React', '新标签'] }
```

## Slug 生成修复

**问题**：中文标题生成空 slug，导致文章 URL 无效

**解决方案**：
```go
func generateSlug(title string) string {
    // 如果没有拉丁字母，使用时间戳
    if !hasAlphaNum || slug == "" {
        slug = "post-" + time.Now().Format("20060102150405")
    }
    return slug
}
```

**数据库修复**：
```sql
UPDATE posts SET slug='qing-qing-de-li-kai' WHERE id=7;
```
