### 数据库设置值污染修复（第二次）
**问题**：站点名称前台显示 `http://localhost:3002\`
**原因**：
- `site_title` 值被污染为 `" http://localhost:3002\"`
- `site_name` 字段不应存在（正确字段是 `site_title`）
- `active_theme` 被错误设置为 `"老灯Blog\"`（站点名被误存为主题名）

**修复**：
```sql
DELETE FROM settings WHERE key='site_name';
UPDATE settings SET value='"老灯Blog"' WHERE key='site_title';
UPDATE settings SET value='"dianyan-blog"' WHERE key='active_theme';
```

**重要发现**：settings 表中字符串值必须是 JSON 格式（带引号），因为后端使用 `json.Marshal`/`json.Unmarshal`

## 关键教训
1. **静态资源路径**：FontAwesome 使用 `/fontawesome/`，不是 `/themes/fontawesome/`
2. **系统设置字段名**：前端必须与后端 key 完全一致（`site_title` 不是 `site_name`）
3. **系统设置数据格式**：发送扁平对象，不是 `{ category, settings }` 嵌套结构
4. **Google Fonts**：国内环境建议使用系统字体栈，避免外部字体依赖
5. **settings 表存储格式**：字符串值必须是 JSON 格式（`"老灯Blog"` 而不是 `老灯Blog`）
