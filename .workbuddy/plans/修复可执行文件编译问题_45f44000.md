## 问题分析

用户报告编译出的可执行文件 `catter-cms.exe` 无法在当前系统运行。

### 根本原因

`public/embed.go` 文件缺失，导致 Go 编译时找不到 `catter-cms/public` 包。

错误信息：

```
actions\render.go:4:2: package catter-cms/public is not in std (F:\go\src\catter-cms\public)
```

### 解决方案

创建 `public/embed.go` 文件，嵌入 public 目录下的静态资源（assets、favicon.svg、index.html 等）到可执行文件中。

## 技术方案

### 问题定位

- `actions/render.go` 导入了 `catter-cms/public` 包
- `public` 目录缺少 `embed.go` 文件定义该包
- 参考项目中已有的 `templates/embed.go` 和 `locales/embed.go` 实现

### 修复方案

创建 `public/embed.go`，使用 Go 1.16+ 的 `embed` 功能嵌入静态资源：

```
package public

import (
    "embed"
    "io/fs"
    "github.com/gobuffalo/buffalo"
)

//go:embed assets favicon.svg index.html vite.svg
var files embed.FS

func FS() fs.FS {
    return buffalo.NewFS(files, "public")
}
```

### 目录结构

```
F:/Catter-CMS/
├── public/
│   ├── assets/          # 前端构建输出
│   ├── favicon.svg
│   ├── index.html
│   ├── vite.svg
│   └── embed.go         # [NEW] 静态资源嵌入文件
└── ...
```
