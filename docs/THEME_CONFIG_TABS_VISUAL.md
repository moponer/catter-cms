## 🎯 标签样式详解

### 标签头部渐变背景

```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

**视觉效果**:
```
╔═════════════════════════════════════════════════════════╗
║  从紫蓝(667eea) → 紫色(764ba2) 的 135° 渐变             ║
╚═════════════════════════════════════════════════════════╝
```

### 标签状态

#### 未激活标签
```
┌─────────────┐
│ Hero模块⑻   │  ← rgba(255, 255, 255, 0.15) 半透明白色
└─────────────┘  ← rgba(255, 255, 255, 0.8) 白色文字
```

#### 悬停标签
```
┌─────────────┐
│ Hero模块⑻   │  ← rgba(255, 255, 255, 0.25) 更亮的背景
└─────────────┘  ← #ffffff 纯白色文字
```

#### 激活标签
```
┏━━━━━━━━━━━━━┓
┃ 外观设置⑸   ┃  ← #ffffff 纯白背景
┗━━━━━━━━━━━━━┛  ← #667eea 紫蓝色文字
   ↑              ← font-weight: 600 加粗
   └─ box-shadow: 0 -2px 8px rgba(0,0,0,0.1) 阴影
```

## 🎨 颜色方案

### 渐变色
- **起点**: `#667eea` (紫蓝色)
- **终点**: `#764ba2` (紫色)
- **角度**: `135°` (对角渐变)

### 文字颜色
- **未激活**: `rgba(255, 255, 255, 0.8)` (半透明白)
- **激活**: `#667eea` (紫蓝色)
- **悬停**: `#ffffff` (纯白色)

### 背景颜色
- **标签头部**: 渐变色
- **未激活标签**: `rgba(255, 255, 255, 0.15)`
- **激活标签**: `#ffffff`
- **内容区域**: `#f9fafb` (浅灰)
- **配置卡片**: `#ffffff` (白色)

## 🔧 技术实现

### Element Plus Tabs 组件

```vue
<el-tabs 
  v-model="activeTab" 
  type="card" 
  class="config-tabs"
>
  <el-tab-pane
    v-for="group in configGroups"
    :key="group.id"
    :label="group.label"
    :name="group.id"
  >
    <template #label>
      <div class="tab-label">
        <el-icon v-if="group.icon">
          <component :is="group.icon" />
        </el-icon>
        <span>{{ group.label }}</span>
        <el-badge :value="group.fields.length" />
      </div>
    </template>
    
    <!-- 配置表单 -->
  </el-tab-pane>
</el-tabs>
```

### CSS 深度选择器

```css
.config-tabs :deep(.el-tabs__item) {
  /* 自定义标签样式 */
}

.config-tabs :deep(.el-tabs__item.is-active) {
  /* 激活状态样式 */
}
```

## ✨ 动画效果

### 标签切换
- **过渡时间**: `0.3s`
- **过渡类型**: `ease`
- **效果**: 平滑的颜色和阴影变化

- **背景变化**: `rgba(255, 255, 255, 0.15)` → `rgba(255, 255, 255, 0.25)`
- **文字变化**: `rgba(255, 255, 255, 0.8)` → `#ffffff`
- **平滑过渡**: 所有变化都有动画
