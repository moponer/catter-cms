# Catter CMS 主题标签语法速查表

## 基础语法

### 变量输出
```html
{{ .variable }}              <!-- 输出变量 -->
{{ .object.Property }}       <!-- 输出对象属性 -->
{{ .array.[0] }}             <!-- 输出数组元素 -->
```

### 配置访问
```html
{{ getConfig "path" "default" }}  <!-- 获取配置值（推荐） -->
{{ .config.key }}                  <!-- 直接访问（不推荐） -->
```

## 控制结构

### 条件判断
```html
<!-- if -->
{{ if .condition }}
    内容
{{ end }}

<!-- if-else -->
{{ if .condition }}
    内容A
{{ else }}
    内容B
{{ end }}

<!-- if-else if-else -->
{{ if eq .status "published" }}
    已发布
{{ else if eq .status "draft" }}
    草稿
{{ else }}
    其他
{{ end }}
```

### 循环
```html
<!-- 基础循环 -->
{{ range .items }}
    {{ .Name }}
{{ end }}

<!-- 带索引循环 -->
{{ range $index, $item := .items }}
    <div class="item-{{ $index }}">
        {{ $item.Name }}
    </div>
{{ end }}
```

## 比较函数

```html
{{ eq .a .b }}      <!-- 等于 -->
{{ gt .a .b }}      <!-- 大于 -->
{{ lt .a .b }}      <!-- 小于 -->
{{ ge .a .b }}      <!-- 大于等于 -->
{{ le .a .b }}      <!-- 小于等于 -->
{{ ne .a .b }}      <!-- 不等于 -->
```

## 自定义函数

### getConfig - 获取配置
```html
{{ getConfig "appearance.colors.primary" "#3B82F6" }}
{{ getConfig "modules.hero.config.title" "欢迎" }}
```

### len - 获取长度
```html
{{ len .posts }}         <!-- 文章数量 -->
{{ len .categories }}    <!-- 分类数量 -->
{{ len "hello" }}        <!-- 字符串长度 -->
```

### default - 默认值
```html
{{ default .value "默认值" }}
```

### asset_path - 资源路径
```html
{{ asset_path "css/style.css" }}  <!-- /themes/theme-name/css/style.css -->
```

### 字符串处理
```html
{{ lower "HELLO" }}      <!-- hello -->
{{ upper "world" }}      <!-- WORLD -->
{{ trim "  text  " }}    <!-- text -->
```

### safe - HTML不转义
```html
{{ safe "<strong>粗体</strong>" }}
```

## 常用数据访问

### 站点信息
```html
{{ .site.title }}         <!-- 站点标题 -->
{{ .site.description }}   <!-- 站点描述 -->
{{ .site.year }}          <!-- 当前年份 -->
```

### 文章数据
```html
{{ .post.Title }}          <!-- 标题 -->
{{ .post.Slug }}           <!-- URL别名 -->
{{ .post.Content }}        <!-- 内容 -->
{{ .post.Excerpt }}        <!-- 摘要 -->
{{ .post.Views }}          <!-- 阅读数 -->
{{ .post.PublishedAt }}    <!-- 发布时间 -->
{{ .post.Category.Name }}  <!-- 分类名 -->
```

### 时间格式化
```html
{{ .post.PublishedAt.Format "2006-01-02" }}       <!-- 2026-03-19 -->
{{ .post.PublishedAt.Format "2006年01月02日" }}   <!-- 2026年03月19日 -->
{{ .post.PublishedAt.Format "15:04:05" }}         <!-- 14:30:45 -->
```

### 菜单数据
```html
{{ range .headerMenu.Items }}
    <a href="{{ .URL }}" {{ if eq .Target "_blank" }}target="_blank"{{ end }}>
        {{ .Label }}
    </a>
{{ end }}
```

## 组合使用示例

### 带条件的内容显示
```html
{{ if gt (len .posts) 0 }}
    <h2>共 {{ len .posts }} 篇文章</h2>
    {{ range .posts }}
        <article>
            <h3>{{ .Title }}</h3>
            <p>{{ .Excerpt }}</p>
        </article>
    {{ end }}
{{ else }}
    <p>暂无文章</p>
{{ end }}
```

### 带默认值的配置输出
```html
<div style="color: {{ getConfig "appearance.colors.primary" "#3B82F6" }}">
    内容
</div>
```

### 条件性显示模块
```html
{{ if getConfig "modules.hero.enabled" true }}
    <section class="hero">
        <h1>{{ getConfig "modules.hero.config.title" "欢迎" }}</h1>
    </section>
{{ end }}
```

## 常见错误

### ❌ 错误示例
```html
<!-- 错误：未提供默认值 -->
{{ getConfig "appearance.colors.primary" }}

<!-- 错误：缺少空格 -->
{{.variable}}

<!-- 错误：未闭合标签 -->
{{ if .condition }}
    内容

<!-- 错误：错误的比较语法 -->
{{ if .count > 0 }}  <!-- 应使用 gt 函数 -->
```

### ✅ 正确示例
```html
<!-- 正确：提供默认值 -->
{{ getConfig "appearance.colors.primary" "#3B82F6" }}

<!-- 正确：添加空格 -->
{{ .variable }}

<!-- 正确：闭合标签 -->
{{ if .condition }}
    内容
{{ end }}

<!-- 正确：使用比较函数 -->
{{ if gt .count 0 }}
```

## 完整模板示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>{{ .site.title }}</title>
    <style>
        body {
            color: {{ getConfig "appearance.colors.text" "#333" }};
            background: {{ getConfig "appearance.colors.background" "#fff" }};
        }
    </style>
</head>
<body>
    <!-- 导航 -->
    <nav>
        {{ range .headerMenu.Items }}
            <a href="{{ .URL }}">{{ .Label }}</a>
        {{ end }}
    </nav>
    
    <!-- 内容 -->
    <main>
        {{ if gt (len .posts) 0 }}
            {{ range .posts }}
                <article>
                    <h2>{{ .Title }}</h2>
                    <time>{{ .PublishedAt.Format "2006-01-02" }}</time>
                </article>
            {{ end }}
        {{ else }}
            <p>暂无内容</p>
        {{ end }}
    </main>
    
    <!-- 页脚 -->
    <footer>
        <p>&copy; {{ .site.year }} {{ .site.title }}</p>
    </footer>
</body>
</html>
```

---

**记住：**
- ✅ 始终提供默认值
- ✅ 使用 `getConfig` 访问配置
- ✅ 使用 `asset_path` 引用资源
- ✅ 检查变量是否存在
- ✅ 使用比较函数而不是运算符

**避免：**
- ❌ 直接访问 `.config` 对象（使用 `getConfig` 代替）
- ❌ 硬编码资源路径（使用 `asset_path` 代替）
- ❌ 忘记闭合标签
- ❌ 使用JavaScript风格的比较运算符
