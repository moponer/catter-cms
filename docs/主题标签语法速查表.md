```html
{{ .variable }}              <!-- 输出变量 -->

{{ .array.[0] }}             <!-- 输出数组元素 -->
```

## 配置访问（重要）

主题配置采用**扁平格式**，直接使用字段名访问：

```html
<!-- 正确：从 theme.Config 扁平存储中直接获取 -->
{{ .config.primaryColor }}                    <!-- 获取主色 -->
{{ .config.sidebarEnabled }}                   <!-- 获取侧边栏开关 -->
{{ .config.heroTitle }}                       <!-- 获取Hero标题 -->

<!-- 不推荐：使用 getConfig 函数（仅在嵌套结构时需要） -->
{{ getConfig "primaryColor" "#FF6B6B" }}
```

**注意**：配置值直接存储在 `.config` 对象中，key 就是 theme.yml 中的字段名（如 `primaryColor`、`sidebarEnabled`），不需要使用点分隔路径。

## 比较函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `eq a b` | 等于 | `{{ eq .status "published" }}` |
| `gt a b` | 大于 | `{{ gt .views 100 }}` |
| `lt a b` | 小于 | `{{ lt .count 0 }}` |
| `ge a b` | 大于等于 | `{{ ge .age 18 }}` |
| `le a b` | 小于等于 | `{{ le .price 100 }}` |
| `ne a b` | 不等于 | `{{ ne .status "draft" }}` |

## 模板函数完整列表

### 配置相关

```html
<!-- getConfig - 获取配置值（支持默认值） -->
{{ getConfig "key" "default_value" }}
{{ getConfig "primaryColor" "#FF6B6B" }}
```

### 资源路径

```html
<!-- asset_path - 生成主题资源路径 -->
{{ asset_path "css/style.css" }}  <!-- 输出: /themes/theme-name/css/style.css -->

<!-- current_theme - 获取当前主题名称 -->
{{ current_theme }}  <!-- 输出: duocai-blog -->
```

### 字符串处理

```html
{{ lower "HELLO" }}      <!-- hello -->
{{ upper "world" }}      <!-- WORLD -->
{{ trim "  text  " }}    <!-- text -->
{{ substr "Hello" 0 3 }} <!-- Hel -->
```

### 数字运算

```html
{{ add 5 3 }}   <!-- 8 -->
{{ sub 5 3 }}   <!-- 2 -->
{{ div 10 3 }}  <!-- 3 (整数除法) -->
{{ mod 10 3 }}  <!-- 1 (取模) -->
{{ int "42" }}  <!-- 42 -->
```

### 集合操作

```html
{{ len .posts }}              <!-- 获取集合长度 -->
{{ first 5 .posts }}          <!-- 获取前5个元素 -->
{{ iterate 10 }}              <!-- 生成 0-9 的数字序列 -->
{{ in "active" .statusList }} <!-- 判断元素是否在集合中 -->

<!-- where - 过滤集合 -->
{{ range where .posts "Status" "published" }}
    {{ .Title }}
{{ end }}
```

### 日期时间

```html
<!-- dateFormat - 日期格式化（Go时间格式） -->
{{ dateFormat "2006-01-02" .post.PublishedAt }}      <!-- 2026-03-26 -->
{{ dateFormat "2006年01月02日" .post.PublishedAt }}   <!-- 2026年03月26日 -->
{{ dateFormat "15:04:05" .post.PublishedAt }}        <!-- 14:30:45 -->
```

### HTML处理

```html
<!-- safe - 标记HTML为安全（不转义）- 谨慎使用 -->
{{ safe "<strong>粗体</strong>" }}

<!-- markdownHTML - Markdown转HTML -->
{{ markdownHTML .post.Content }}
```

### JSON处理

```html
<!-- json_decode - 解析JSON字符串为切片 -->
{{ range json_decode .config.footerLinks }}
    <a href="{{ .url }}">{{ .name }}</a>
{{ end }}

<!-- ensureSlice - 确保返回切片类型 -->
{{ range ensureSlice .config.items }}
    {{ . }}
{{ end }}
```

### 默认值

```html
<!-- default - 提供默认值 -->
{{ default .value "暂无内容" }}
{{ default .post.Thumbnail "/images/default.jpg" }}
```

## 常见错误

### ❌ 错误示例

```html
<!-- 错误：忘记空格 -->
{{.variable}}

<!-- 错误：使用JavaScript比较运算符 -->
{{ if .count > 0 }}  <!-- 应使用 gt 函数 -->
{{ if .count >= 0 }} <!-- 应使用 ge 函数 -->

<!-- 错误：在需要嵌套路径时使用扁平key -->
{{ getConfig "colors.primary" }} <!-- 配置是扁平的，应该用 .config.primaryColor -->
```

### ✅ 正确示例

```html
<!-- 正确：添加空格 -->
{{ .variable }}

<!-- 正确：使用比较函数 -->
{{ if gt .count 0 }}
{{ if ge .count 0 }}

<!-- 正确：直接访问扁平配置 -->
{{ .config.primaryColor }}
```

## 完整模板示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>{{ .site.title }}</title>
    <link rel="stylesheet" href="{{ asset_path "css/base.css" }}">
    <style>
        :root {
            --primary: {{ .config.primaryColor }};
            --accent: {{ .config.accentColor }};
        }
    </style>
</head>
<body>
    <!-- 导航 -->
    <nav>
        {{ range .headerMenu.Items }}
            <a href="{{ .URL }}">{{ .Label }}</a>
        {{ end }}
    </nav>

    <!-- Hero区域 -->
    {{ if .config.heroEnabled }}
    <header class="hero" style="background: {{ .config.bgGradient }}">
        <h1>{{ .config.heroTitle }}</h1>
        <p>{{ .config.heroSubtitle }}</p>
    </header>
    {{ end }}

    <!-- 主内容 -->
    <main class="main-{{ .config.sidebarPosition }}">
        <div class="content">
            {{ range .posts }}
                <article class="post-card">
                    <h2>{{ .Title }}</h2>
                    <time>{{ dateFormat "2006-01-02" .PublishedAt }}</time>
                    <p>{{ default .Excerpt "暂无摘要" }}</p>
                    {{ if .config.showViews }}
                        <span>阅读 {{ .Views }}</span>
                    {{ end }}
                </article>
            {{ end }}
        </div>

        <!-- 侧边栏 -->
        {{ if and .config.sidebarEnabled (gt (len .sidebarWidgets) 0) }}
        <aside class="sidebar">
            {{ range .sidebarWidgets }}
                <div class="widget">
                    <h3>{{ .Title }}</h3>
                    {{ .Content }}
                </div>
            {{ end }}
        </aside>
        {{ end }}
    </main>

    <!-- 页脚 -->
    <footer>
        <p>&copy; {{ .site.year }} {{ .site.title }}</p>
        <div>
            {{ range json_decode .config.footerLinks }}
                <a href="{{ .url }}">{{ .name }}</a>
            {{ end }}
        </div>
    </footer>
</body>
</html>
```

## 记住

- ✅ 配置是**扁平格式**，直接用 `.config.字段名` 访问
- ✅ 使用 `asset_path` 引用主题资源
- ✅ 使用 `dateFormat` 格式化日期
- ✅ 使用比较函数（`eq`, `gt`, `lt` 等）而不是运算符
- ✅ 始终使用空格分隔模板语法

## 避免

- ❌ 使用点分隔路径访问配置（除非确实需要嵌套）
- ❌ 使用 JavaScript 风格的比较运算符
- ❌ 忘记闭合标签
- ❌ `safe` 函数慎用，可能导致 XSS
