# 主题配置使用指南

## 🎨 概述

Catter CMS 的主题配置系统允许您通过管理后台实时定制主题外观，无需修改代码。配置会自动保存到数据库，并立即在前台生效。

## 📍 访问主题配置

1. 登录管理后台：http://127.0.0.1:3002/admin
2. 进入"主题管理"页面
3. 点击"配置"按钮
4. 修改配置后点击"保存"

## 🎯 配置项说明

### 1. 外观设置 (Appearance)

#### 颜色配置 (Colors)
```yaml
appearance:
  colors:
    primary: "#3B82F6"      # 主色调（按钮、链接、强调色）
    secondary: "#8B5CF6"    # 次要色调（渐变、装饰）
    accent: "#06B6D4"       # 强调色（特殊元素）
```

**使用示例**：
- 主色调用于：Logo、按钮、链接hover、分类标签
- 次要色调用于：渐变背景、装饰元素
- 强调色用于：特殊提示、计数标签

#### 布局配置 (Layout)
```yaml
appearance:
  layout:
    sidebar: "right"        # 侧边栏位置：left / right
    width: "1280px"         # 内容区最大宽度
```

#### 字体配置 (Typography)
```yaml
appearance:
  typography:
    baseFont: "'Inter', 'Noto Sans SC', sans-serif"
```

### 2. 模块设置 (Modules)

#### Hero 区域配置
```yaml
modules:
  hero:
    enabled: true           # 是否显示Hero区域
    config:
      title: "欢迎来到我的博客"
      subtitle: "分享技术、记录生活、探索未知"
      backgroundType: "gradient"   # 背景：gradient / image
      backgroundImage: ""          # 背景图片URL
      ctaText: "开始阅读"
      ctaUrl: "/blog"
      showCta: true
```

### 3. 小工具配置 (Widgets)

#### 作者信息
```yaml
widgets:
  author:
    name: "博主"
    bio: "热爱技术，热爱生活"
    avatar: ""              # 头像URL
    showSocial: true
```

#### 搜索组件
```yaml
widgets:
  search:
    enabled: true
    placeholder: "搜索文章..."
    buttonText: "搜索"
```

#### 最近文章
```yaml
widgets:
  recent-posts:
    enabled: true
    count: 5
    showDate: true
    showThumbnail: true
```

### 4. 页面配置 (Pages)

#### 首页配置
```yaml
pages:
  home:
    layout: "two-column"           # 布局：one-column / two-column
    sidebarPosition: "right"       # 侧边栏位置
    postsPerPage: 10
    showExcerpt: true
    excerptLength: 150
    sidebarWidgets:
      - search
      - author
      - recent-posts
      - categories
      - tags
```

#### 文章页配置
```yaml
pages:
  post:
    layout: "two-column"
    showAuthor: true
    showToc: true                  # 显示目录
    showRelated: true              # 显示相关文章
    relatedCount: 6
    showShare: true                # 显示分享按钮
    showPrevNext: true             # 显示上下篇
```

## 🔄 配置动态加载机制

### 后端处理流程

1. **数据库保存**
```go
// 用户在后台修改配置 → 保存到 theme_configs 表
{
  "theme_name": "catter-blog",
  "config": {
    "appearance.colors.primary": "#3B82F6",
    "modules.hero.config.title": "欢迎来到我的博客",
    ...
  }
}
```

2. **加载配置**
```go
// 主题加载时 → 从数据库读取配置 → 转换为嵌套结构
{
  "appearance": {
    "colors": {
      "primary": "#3B82F6",
      "secondary": "#8B5CF6"
    }
  },
  "modules": {
    "hero": {
      "config": {
        "title": "欢迎来到我的博客"
      }
    }
  }
}
```

3. **模板渲染**
```html
<!-- 模板中使用 getConfig 函数访问配置 -->
<h1>{{ getConfig "modules.hero.config.title" "默认标题" }}</h1>
```

### 前端访问方式

**方式1：使用 getConfig 函数（推荐）**
```html
<body style="color: {{ getConfig "appearance.colors.primary" "#333" }}">
```

**方式2：直接访问配置对象**
```html
<body style="color: {{ .config.appearance.colors.primary }}">
```

## 🎨 配置实时生效

### 自动重载机制

当您在后台保存主题配置后，系统会：

1. ✅ 保存配置到数据库
2. ✅ 清除内存中的旧配置
3. ✅ 从数据库重新加载配置
4. ✅ 更新主题对象
5. ✅ 下次页面刷新时立即生效

**代码实现**：
```go
// gin-app/internal/services/theme.go
func UpdateThemeConfig(themeName string, config map[string]interface{}) error {
    // 1. 保存到数据库
    models.SaveThemeConfig(themeName, config)
    
    // 2. 从数据库重新加载
    reloadedConfig, _ := models.GetThemeConfig(themeName)
    
    // 3. 更新内存
    theme := GetTheme(themeName)
    theme.Config = reloadedConfig
    
    return nil
}
```

## 🌈 主题定制示例

### 示例1：修改主题色为紫色

**步骤**：
1. 进入"主题管理" → "配置"

## 📋 配置文件映射

### theme.yml 定义

```yaml
name: catter-blog
version: 1.0.0

configDefinition:
  - section: appearance
    label: 外观设置
    fields:
      - name: primary
        label: 主色调
        type: color
        default: "#3B82F6"
```

### 数据库存储

```sql
-- theme_configs 表
theme_name: "catter-blog"
config: '{"appearance.colors.primary":"#8B5CF6"}'
```

### 模板使用

```html
<style>
  --primary: {{ getConfig "appearance.colors.primary" "#3B82F6" }};
</style>
```

## ⚠️ 注意事项

1. **配置优先级**
   - 数据库配置 > theme.yml默认配置 > 模板默认值

2. **配置路径格式**
   - 使用点分隔：`appearance.colors.primary`
   - 嵌套访问：`config["appearance"]["colors"]["primary"]`

3. **必须提供默认值**
   ```html
   <!-- ✅ 正确 -->
   {{ getConfig "appearance.colors.primary" "#3B82F6" }}
   
   <!-- ❌ 错误（缺少默认值） -->
   {{ getConfig "appearance.colors.primary" }}
   ```

4. **配置类型**
   - 颜色值需要包含 `#` 前缀
   - 布尔值为 `true` / `false`
   - 数组使用 YAML 列表格式

## 🎯 最佳实践

### 1. 使用CSS变量

```html
<style>
:root {
    --primary: {{ getConfig "appearance.colors.primary" "#3B82F6" }};
}

.button {
    background: var(--primary);
}
</style>
```

### 2. 条件渲染

```html
{{ if getConfig "modules.hero.enabled" true }}
    <section class="hero">...</section>
{{ end }}
```

### 3. 提供合理的默认值

```html
<!-- 确保即使配置缺失也能正常显示 -->

```
