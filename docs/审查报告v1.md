**修复方案**：创建了新的 `spa.go` 中间件，重新设计了静态文件服务逻辑：

**新增文件**: `gin-app/internal/middleware/spa.go`

```go
// 核心改进：
// 1. SPA 中间件在文件不存在时返回 index.html
// 2. Static handler 正常提供静态文件
// 3. NoRoute fallback 处理未匹配路径

r.Use(middleware.SPAMiddleware(adminDistPath, "/admin"))
r.Static("/admin", adminDistPath)

r.NoRoute(func(c *gin.Context) {
    path := c.Request.URL.Path
    if strings.HasPrefix(path, "/admin") || path == "/login" {
        c.Header("Content-Type", "text/html; charset=utf-8")
        c.File(adminDistPath + "/index.html")
        return
    }
    // ...
})
```

```go
func getCSPHeader(c *gin.Context) string {
    // 开发环境使用宽松的 CSP
    if gin.Mode() == gin.DebugMode {
        return "default-src 'self' 'unsafe-inline' 'unsafe-eval'; ..."
    }
    // 生产环境使用严格的 CSP
    return "default-src 'self'; script-src 'self'; ..."
}
```

### P9: TODO 注释未实现 ✅ 已实现

**scheduler.go 中实现的 4 个功能**：

1. **executeBackup** - 数据库备份
   - 支持 SQLite 数据库备份
   - 备份文件命名：`catter_backup_20260325_143052.db`
   - 自动清理旧备份（保留最近 10 个）

2. **executeCleanup** - 系统清理
   - 清理上传目录临时文件
   - 清理过期的任务执行记录
   - 清理系统日志（保留最近 7 天）
   - 清理 Sitemap 缓存

3. **executePublish** - 定时发布
   - 自动发布已到预定时间的文章
   - 查询 `status='scheduled'` 且 `scheduled_at <= now()` 的文章

4. **executeCustom** - 自定义命令
   - 白名单命令验证
   - 危险命令拦截（rm, del, shutdown 等）
   - 标准输出/错误捕获

**新增文件**: `post.go` 中添加 `PublishPost()` 和 `GetScheduledPosts()`
