# Catter CMS 开发与生产文件清单

## 开发目录 (gin-app/)

`gin-app/` 目录包含 Go 后端源代码，**生产环境不需要部署**：

```
gin-app/
├── cmd/
│   └── main.go              # 入口文件 - 编译后不需要
├── internal/                # 内部代码 - 编译后不需要
│   ├── handlers/
│   ├── middleware/
│   ├── models/
│   └── services/
├── config/                  # 配置代码 - 编译后不需要
├── go.mod                   # Go模块定义 - 编译后不需要
├── go.sum                   # Go依赖校验 - 编译后不需要
├── config.yaml              # ⚠️ 需要复制到生产环境
├── templates/               # ⚠️ 需要复制到生产环境
│   ├── 404.html
│   └── themes/
└── catter.db                # 数据库文件（开发测试用）
```

## 生产环境只需要以下文件

### 1. 可执行文件（编译生成）
```
catter-cms.exe              # Windows
catter-cms                  # Linux/Mac
```

**生成命令：**
```bash
cd gin-app
go build -o ../catter-cms.exe ./cmd/main.go
```

### 2. 配置文件（从 gin-app 复制）
```
config.yaml                 # 主配置文件
```

### 3. 前端文件（构建生成）
```
admin/dist/                 # npm run build 生成的文件
├── index.html
└── assets/
```

**生成命令：**
```bash
cd admin
npm run build
```

### 4. 模板文件（从 gin-app 复制）
```
templates/
├── 404.html
themes/
├── catter-blog/
├── catter-cms-official/
└── enterprise-website/
```

### 5. 数据文件（运行时生成）
```
catter.db                   # SQLite数据库（首次运行自动创建）
uploads/                    # 上传文件目录（首次运行自动创建）
```

## 部署包制作脚本

### Windows (deploy.bat)

```batch
@echo off
set DEPLOY_DIR=./deploy

echo 创建部署目录...
mkdir %DEPLOY_DIR%\admin\dist
mkdir %DEPLOY_DIR%\templates\themes
mkdir %DEPLOY_DIR%\uploads

echo 编译后端...
cd gin-app
go build -o ../%DEPLOY_DIR%/catter-cms.exe ./cmd/main.go
cd ..

echo 构建前端...
cd admin
call npm run build
xcopy /s /e /y dist\* ..\%DEPLOY_DIR%\admin\dist\
cd ..

echo 复制模板文件...
xcopy /s /e /y gin-app\templates\* %DEPLOY_DIR%\templates\

echo 复制配置文件...
copy gin-app\config.yaml %DEPLOY_DIR%\

echo 部署包已创建在 %DEPLOY_DIR% 目录
echo 请修改 %DEPLOY_DIR%\config.yaml 中的配置后再部署
pause
```

### Linux/Mac (deploy.sh)

```bash
#!/bin/bash

DEPLOY_DIR="./deploy"

echo "创建部署目录..."
mkdir -p $DEPLOY_DIR/admin/dist
mkdir -p $DEPLOY_DIR/templates/themes
mkdir -p $DEPLOY_DIR/uploads

echo "编译后端..."
cd gin-app
go build -o ../$DEPLOY_DIR/catter-cms ./cmd/main.go
cd ..

echo "构建前端..."
cd admin
npm run build
cp -r dist/* ../$DEPLOY_DIR/admin/dist/
cd ..

echo "复制模板文件..."
cp -r gin-app/templates/* $DEPLOY_DIR/templates/

echo "复制配置文件..."
cp gin-app/config.yaml $DEPLOY_DIR/

echo "部署包已创建在 $DEPLOY_DIR 目录"
echo "请修改 $DEPLOY_DIR/config.yaml 中的配置后再部署"
```

## 文件大小对比

| 项目 | 开发环境 | 生产环境 |
|-----|---------|---------|
| gin-app/ | ~50MB（含源码和依赖） | 不需要 |
| admin/node_modules | ~500MB | 不需要 |
| admin/dist | 不需要 | ~5MB |
| catter-cms.exe | 不需要 | ~15MB |
| **总计** | **~550MB** | **~20MB** |

## 部署步骤

1. **开发机执行：**
   ```bash
   ./deploy.sh    # 或 deploy.bat
   ```

2. **将 deploy/ 目录上传到服务器**

3. **服务器配置：**
   ```bash
   cd deploy
   # 修改 config.yaml 中的配置
   vim config.yaml
   
   # 运行
   ./catter-cms.exe
   ```

## 总结

- ✅ **需要部署**：`catter-cms.exe`, `config.yaml`, `admin/dist/`, `templates/`
- ❌ **不需要部署**：`gin-app/` (源代码), `admin/node_modules/` (依赖)
- 🔄 **运行时生成**：`catter.db`, `uploads/`

生产环境只需要约 **20MB**，而开发环境需要 **550MB+**。
